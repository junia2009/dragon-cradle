# 🐉 Dragon Cradle

ドラゴンを育てて戦わせる育成バトルゲーム

> A dragon breeding and battle game built with Three.js and Web Audio API

![Version](https://img.shields.io/badge/version-v3.0.0-E6C47A)

## 🎮 遊び方

### 1. 卵を選ぶ

| 属性 | 役割 | 特徴 |
| ---- | ---- | ---- |
| 🔥 炎 | アタッカー | 高い攻撃力で押し切る |
| ❄️ 氷 | タンク | 厚い体力と守りで耐える |
| ⚡ 雷 | スピード | 先手・回避・会心で翻弄 |
| 🌑 闇 | バランス | 相性の不利を受けない |

相性は **炎 › 氷 › 雷 › 炎**（有利 ×1.3 / 不利 ×0.77）。闇はすべて等倍。

### 2. 卵を孵す

卵の揺れがいちばん大きくなった瞬間にタップ。PERFECT を連続させるとコンボで孵化が早まります。
タップ音は流れている曲のコードに合わせて鳴ります。

### 3. 育てる

- **えさ / 攻撃鍛錬 / 守り鍛錬 / 速さ鍛錬** でステータスを上げる（スタミナ 1 消費・まれに大成功）
- 鍛錬は **現在の Lv に応じて効率が頭打ち** になる → バトルで Lv を上げると再び伸びる
- スタミナは最大 5、90 秒で 1 回復、**バトル勝利でも +1**
- 成長ゲージが 60 に達すると成体に進化（素の能力 1.2 倍）
- 鍛錬の傾向でタイプが決まり、必殺技が変わる

| タイプ | 必殺技 | 効果 |
| ---- | ---- | ---- |
| バランス型 | ドラゴンブレス | 威力 2.5 倍・属性不利を無視 |
| アタッカー型 | バーサークブロー | 威力 3.0 倍・次の被ダメ +30% |
| タンク型 | アイアンウォール | 威力 1.0 倍・被ダメ 70% カット・HP 12% 回復 |
| スピード型 | サンダーラッシュ | 0.85 倍 × 3 連撃・必ず先制・会心率 UP |

### 4. バトル

- ターン制（攻撃 / 必殺技 / 守り）。行動順は SPD で決まる
- 敵は数ターンごとに **力をためて強攻撃** → 予告を見て守る
- 5 の倍数 Lv は **ボス戦**（HP 多め・強攻撃が頻繁・HP 半分で激昂）
- 勝利で経験値・スコア・スタミナ。負けても経験値の 25% は得られる
- 戦闘中に画面を離れると撤退扱い（連勝リセット）
- AUTO で自動戦闘。キーボードは 1 / 2 / 3 / A

## ⚖️ ゲームバランス

バランス計算は `js/balance.js` に純粋関数として分離してあり、Node でシミュレーションできます。

```bash
npm run simulate           # 属性 × 鍛錬方針ごとの到達 Lv と勝率帯
PROBE=1 npm run simulate   # 到達時のステータスと敵ステータスの比較
```

調整の目安（鍛錬しながら進めた場合の勝率）：

| 敵 Lv | 1–10 | 11–20 | 21–35 | 36–50 |
| ---- | ---- | ---- | ---- | ---- |
| 勝率 | ほぼ全勝 | 約 80–90% | 約 65–75% | 約 55–65% |

鍛錬しないと Lv10 前後で壁に当たり、4 属性 × 4 方針の差は各帯で ±6% 程度に収まるよう調整しています。

## 🎼 インタラクティブミュージック

`js/music.js` は音声ファイルを使わず、Web Audio API でその場で演奏します。

- **縦の再構成** — パート（ドラム・ベース・リード・トレモロ等）をゲーム状況に応じてフェードイン / アウト
  - 孵化：ゲージが溜まるほど楽器が増え、満タン間近で心音とトレモロが加わる
  - 戦闘：敵の HP を削るほど盛り上がり、敵が力をためるとトレモロとスネアロール、自分の HP が減ると心音とローパスで音がこもる
- **横の再構成** — 4 小節ごとのフレーズ境界で通常 ⇄ クライマックスのセクションを切替
- **スティンガー** — 勝利 / 敗北 / レベルアップ / 進化 / 孵化を拍・小節に合わせて挿入し、そのまま次の曲へつなぐ
- **調と旋法** — 育成曲は属性ごとに旋法が変わる（炎=ドリアン、氷=リディアン、雷=ミクソリディアン、闇=エオリアン）。成体になると編成が厚くなる。ボス戦はフリジアンに
- **ハーモニック SE** — タップ・鍛錬・攻撃音を「いま鳴っているコード」の構成音で鳴らす

## 🚀 ローカルで動かす

```bash
git clone https://github.com/junia2009/dragon-cradle.git
cd dragon-cradle
npx http-server -p 8080 -c-1
```

ブラウザで `http://localhost:8080` を開く。

## 🔧 開発ツール — preview.html

`preview.html` はドラゴンモデルの確認・調整に使う開発用ビューアです。

- **属性切替** — 火・氷・雷・闇の4属性をワンクリックで切替
- **成長段階切替** — 幼体 / 成体を即座に切替
- **ドラゴンタイプ切替** — バランス型・アタッカー型・タンク型・スピード型
- **ワイヤーフレーム表示** — メッシュ構造を確認
- **背景切替** — プレビュー（グリッド） / 育成 / 戦闘 の3種類で実際の画面に近い見た目を確認
- **BGM確認** — タイトル / 孵化 / 育成 / 戦闘 の曲を再生し、盛り上がり・危険・緊張・クライマックス・ボスのパラメータやスティンガーをその場で試せる
- **OrbitControls** — マウスドラッグで360度回転、ホイールでズーム

体・翼・頭・目・脚・爪などの各パーツのサイズ・位置・角度を、このプレビューで即座にフィードバックを得ながら調整しました。

```bash
# プレビューツールを開く
http://localhost:8080/preview.html
```
